

# Power BI Report

## Report

**Financial Consumer Complaint Intelligence**

File:

`Financial_Consumer_Complaint_Intelligence.pbix`



## Report Pages

The Power BI report contains five primary analytical pages.

### 1. Consumer Pulse

Overall consumer complaint landscape.

### 2. Complaint Intelligence

Complaint drivers and product/issue relationships.

### 3. Company Intelligence

Company complaint concentration and response outcomes.

### 4. Response & Resolution

Response timing and handling performance.

### 5. Geographic Intelligence

State-level complaint concentration and response patterns.



## Supporting Pages

The report also contains supporting pages for:

* Company Detail drill-through
* Company contextual tooltip
* State contextual tooltip

These pages are not intended to appear in the primary navigation.



## Data Model

### Fact

`Fact_Complaints`

### Dimensions

* `Dim_Date`
* `Dim_Product`
* `Dim_Issue`
* `Dim_Company`
* `Dim_Geography`



## Core Measures

The report uses measures including:

* `Total Complaints`
* `YoY Complaint %`
* `Timely Response %`
* `Median Response Days`
* `P90 Response Days`
* `Complaint Volume`
* `Complaint Share`
* `Dispute Rate`



## Interactivity

The report includes:

* Slicers
* Cross-filtering
* Decomposition tree analysis
* Drill-through
* Report-page tooltips
* Page navigation
