


# Dashboard Guide

## Overview

The Financial Consumer Complaint Intelligence dashboard is organized into five analytical pages.

Each page answers a different question.



# 1. Consumer Pulse

### Question

**What is happening across the consumer-finance complaint landscape?**

Use this page for the initial overview.

You can explore:

* Complaint volume
* Complaint trend
* Product concentration
* State concentration
* Complaint drivers

### Filters

* Year
* Product
* State
* Company



# 2. Complaint Intelligence

### Question

**Why are consumers complaining?**

Use this page to investigate complaint drivers.

### Filters

* Product
* Issue
* Year

### Main interaction

The decomposition tree allows complaint volume to be explored by:

1. Product
2. Issue

The Product × Issue matrix provides a more detailed view of complaint concentration.



# 3. Company Intelligence

### Question

**Where is complaint pressure concentrated, and how are companies responding?**

Use this page for company-level analysis.

### Filters

* Company
* Product
* Year

### Main interactions

Company visuals can be cross-filtered to investigate a specific company's complaint profile.

A company can also be taken into the Company Detail drill-through page.



# 4. Response & Resolution

### Question

**How effectively are consumer complaints being handled?**

Use this page to investigate:

* Timely response
* Median response duration
* P90 response duration
* Response-time bands
* Product-level response performance
* Company response performance

### Response Time Bands

The report uses:

* Same day
* 1–2 days
* 3–5 days
* 6–10 days
* 11–30 days



# 5. Geographic Intelligence

### Question

**Where is complaint pressure concentrated geographically?**

Use this page to explore state-level patterns.

### Filters

* State
* Product
* Year

### Main analysis

The page combines:

* Geographic concentration
* State × Product patterns
* Dispute rate
* State response performance



# Drill-Through

## Company Detail

To open company detail:

1. Go to a company visual.
2. Right-click the company.
3. Select **Drill through**.
4. Select **Company Detail**.

The detail page provides:

* Complaint volume
* Timely response
* Median response
* Dispute rate
* Product complaint profile
* Top issues
* Response outcomes
* Complaint trend

Use the Back button to return to the originating page.



# Report Tooltips

Company and state visuals include contextual report-page tooltips.

Hover over supported visuals to view additional information without leaving the current page.



# Navigation

Use the sidebar navigation to move between the five primary pages.

The supporting drill-through and tooltip pages are intentionally hidden from the main navigation.
